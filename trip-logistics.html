Практический совет
Три брони пересекаются по датам заезда/выезда (Крис отдельно с 4-го, остальные с 5-го) — при заселении в Ginza уточните на ресепшене, что это два разных бронирования на одну семью, чтобы не создать путаницу с номерами.

Пока ни один поезд или timed-ticket (музей, аттракцион) не забронирован. Раздел готов принять брони по мере их появления — тот же формат карточки: направление/место, дата и время, номер брони, короткая заметка.

Практический совет
Единственное, что уже требует действия по времени — поездка в Никко (день 25 Sep). Лимитед-экспресс Tobu (SPACIA X / Revaty Kegon / Spacia Kegon от Kita-Senju) требует отдельного места, и бронь открывается ровно за месяц: для 25 сентября — 25 августа, 09:00 по Японии = 03:00 по Израилю. Если хотите именно SPACIA X — это стоит ловить в первые секунды после открытия окна, обычные Kegon можно брать и позже.

Как забронируете что-то из этого списка — карточка переезжает сюда с реальным номером подтверждения, а в Practical Info соответствующего дня останется только короткая строка-напоминание, без дублирования деталей.
